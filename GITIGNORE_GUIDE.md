# Git Ignore Configuration Guide

## Overview

The `.gitignore` file has been configured to keep your repository clean while ensuring datasets can be tracked but large generated files are ignored.

## What's Ignored

### ✅ Cached Files (IGNORED)
- `__pycache__/` - Python bytecode cache
- `*.pyc`, `*.pyo`, `*.pyd` - Compiled Python files
- `.mypy_cache/`, `.pytest_cache/` - Testing and type-checking caches
- `node_modules/` - NPM packages (UI)
- `.next/`, `dist/`, `build/` - Build artifacts

### ✅ Models (IGNORED - Large Files)
- `models/*/` - All model directories
- `*.pkl`, `*.h5`, `*.pt`, `*.pth` - Trained model files
- `*.bin`, `*.safetensors`, `*.gguf` - LLM model files

**Why:** Model files are large (MBs to GBs) and can be regenerated by training

### ✅ Generated Data (IGNORED)
- `data/balanced/*.jsonl` - Balanced datasets (generated)
- `data/processed/*.jsonl` - Processed data (generated)
- `data/labeled/*.jsonl` - Labeled data (generated)
- `data/raw/*.csv`, `data/raw/*.json` - Raw data files

**Why:** These are large and can be regenerated from source data or scripts

### ✅ Logs (IGNORED)
- `*.log` - All log files
- `training_*.log` - Training logs
- `logs/` - Log directories

### ✅ Environment Files (IGNORED)
- `.env` - Local environment config (contains secrets!)
- `.env.local`, `.env.*.local` - Environment-specific configs
- `docker-compose.override.yml` - Local Docker overrides

### ✅ Test Files (IGNORED)
- `test_batch*.csv`, `test_batch*.json` - Generated test files

### ✅ Monitoring Data (IGNORED)
- `monitoring/prometheus/data/` - Prometheus metrics
- `monitoring/grafana/data/` - Grafana dashboards

## What's Tracked

### ✅ Source Code (TRACKED)
- All `.py` files
- Configuration files (`*.yaml`, `*.toml`)
- Documentation (`*.md`)

### ✅ Small Reference Data (TRACKED)
- `data/taxonomy.yaml` - Category taxonomy
- `data/gazetteer/` - Merchant directory
- `data/few_shot_examples.jsonl` - LLM examples

### ✅ Infrastructure (TRACKED)
- `docker-compose.yaml`, `Dockerfile`
- `requirements.txt`
- Scripts (`scripts/*.py`)

### ✅ UI Source (TRACKED)
- `ui/app/`, `ui/components/` - React components
- `ui/package.json` - Dependencies manifest
- UI configuration files

## Important Notes

### Datasets Policy

**Current configuration:**
- ❌ Large datasets (`.jsonl`, `.csv` in `data/balanced/`, `data/processed/`) are **IGNORED**
- ✅ Small reference files (taxonomy, gazetteer) are **TRACKED**

**To track datasets** (if you want to push them to git):
1. Remove these lines from `.gitignore`:
   ```
   data/balanced/*.jsonl
   data/processed/*.jsonl
   data/labeled/*.jsonl
   ```
2. Add the datasets:
   ```bash
   git add data/balanced/ data/processed/
   ```

**Warning:** Only do this if:
- Your datasets are small (<10MB)
- You're using Git LFS for large files
- You want to version control the exact datasets

### Using Git LFS for Large Files

If you need to track large files, use Git LFS:

```bash
# Install Git LFS
git lfs install

# Track large file patterns
git lfs track "*.jsonl"
git lfs track "*.pkl"
git lfs track "models/**"

# Add the tracking file
git add .gitattributes

# Now add and commit large files
git add data/balanced/
git commit -m "Add datasets with Git LFS"
```

## Cleanup Script

Use the included script to check for files that should be ignored:

```bash
./cleanup-git.sh
```

This script will:
1. Scan for tracked files matching `.gitignore` patterns
2. Show what would be removed
3. Ask for confirmation before removing

To remove a specific file from git (keeping local copy):

```bash
git rm --cached path/to/file
```

To remove a directory from git (keeping local copy):

```bash
git rm --cached -r path/to/directory/
```

## Verify Gitignore

Check what will be ignored:

```bash
# Test if a file would be ignored
git check-ignore -v path/to/file

# List all ignored files in current directory
git status --ignored

# See what's being tracked
git ls-files
```

## Best Practices

1. ✅ **Never commit secrets** - `.env` files are ignored by default
2. ✅ **Keep models out of git** - Use model registries or cloud storage
3. ✅ **Track small datasets** - Only if <10MB or using Git LFS
4. ✅ **Commit `.gitkeep` files** - To preserve empty directory structure
5. ✅ **Update `.gitignore`** - Before adding new file types

## Troubleshooting

### File still tracked after adding to .gitignore?

```bash
# Remove from git cache
git rm --cached path/to/file

# Commit the change
git commit -m "Remove file from tracking"
```

### Accidentally committed large file?

```bash
# Remove from history (USE WITH CAUTION!)
git filter-branch --force --index-filter \
  'git rm --cached --ignore-unmatch path/to/large/file' \
  --prune-empty --tag-name-filter cat -- --all

# Force push (if already pushed)
git push origin --force --all
```

Better: Use [BFG Repo-Cleaner](https://rtyley.github.io/bfg-repo-cleaner/) for this
